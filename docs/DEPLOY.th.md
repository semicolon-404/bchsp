# คู่มือติดตั้งเว็บไซต์โรงพยาบาลบัวเชดบนเซิร์ฟเวอร์

สำหรับผู้ดูแลเซิร์ฟเวอร์ที่จะนำเว็บไซต์ขึ้นใช้งานจริง ทำตามลำดับจากบนลงล่าง ขั้นที่มักถูกข้ามและทำให้ระบบเสียหายภายหลังคือข้อ 6 (งานตั้งเวลา) และข้อ 8 (สำรองข้อมูลออกนอกเครื่อง)

## 1. สิ่งที่เซิร์ฟเวอร์ต้องมี

| รายการ | รุ่น |
|---|---|
| PHP | 8.2 ขึ้นไป พร้อมส่วนขยาย `pdo_mysql`, `mbstring`, `intl`, `gd` (ต้องรองรับ WebP), `zip`, `fileinfo`, `exif`, `openssl` |
| ฐานข้อมูล | MariaDB 10.4 ขึ้นไป หรือ MySQL 8 |
| Composer | 2.x |
| Node.js | 20 ขึ้นไป (ใช้ตอนสร้างไฟล์ CSS/JS เท่านั้น ไม่ต้องรันค้างไว้) |
| เว็บเซิร์ฟเวอร์ | Apache หรือ Nginx ที่มี HTTPS |

โปรแกรม `mysqldump` ต้องเรียกใช้ได้ เพราะระบบสำรองข้อมูลใช้โปรแกรมนี้

## 2. วางไฟล์และติดตั้ง

```bash
git clone https://github.com/semicolon-404/bchsp.git
cd bchsp
composer install --no-dev --optimize-autoloader
npm ci
npm run build
cp .env.example .env
php artisan key:generate
```

ชี้ document root ของเว็บเซิร์ฟเวอร์ไปที่โฟลเดอร์ `public` เท่านั้น ห้ามชี้ที่โฟลเดอร์โปรเจกต์ เพราะจะทำให้ไฟล์ `.env` และไฟล์สำรองข้อมูลถูกเปิดอ่านจากภายนอกได้

## 3. ตั้งค่าไฟล์ `.env`

ค่าที่ต้องแก้ทุกครั้ง:

```ini
APP_ENV=production
APP_DEBUG=false
APP_URL=https://ชื่อโดเมนจริง

DB_CONNECTION=mariadb
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=ชื่อฐานข้อมูล
DB_USERNAME=ผู้ใช้ฐานข้อมูล
DB_PASSWORD=รหัสผ่านฐานข้อมูล

STAFF_TWO_STEP=true
BACKUP_MYSQLDUMP=mysqldump
BACKUP_KEEP_DAYS=14
```

- `APP_URL` ต้องตรงกับที่อยู่ที่ใช้เปิดเว็บไซต์จริง รวมถึงพอร์ต ถ้าไม่ตรง รูปภาพและเอกสารที่อัปโหลดจะเปิดไม่ได้ หน้าสถานะระบบจะเตือนข้อนี้ให้
- `APP_DEBUG` ต้องเป็น `false` ถ้าเปิดไว้ หน้าแจ้งข้อผิดพลาดจะแสดงข้อมูลภายในของระบบให้ทุกคนเห็น
- `STAFF_TWO_STEP=true` บังคับให้ทุกคนที่เข้าหลังบ้านตั้งค่ายืนยันตัวตนสองขั้น
- บน Windows ให้ใส่ที่อยู่เต็มของ mysqldump เช่น `BACKUP_MYSQLDUMP=C:/xampp/mysql/bin/mysqldump.exe`
- ผู้ใช้ฐานข้อมูลควรมีสิทธิ์เฉพาะฐานข้อมูลของเว็บนี้ ไม่ใช้ `root`

## 4. สร้างฐานข้อมูลและข้อมูลตั้งต้น

```bash
php artisan migrate --force
php artisan db:seed --force
php artisan storage:link
```

`db:seed` เพิ่มรายชื่อหน่วยงาน 12 หน่วยงานและลิงก์บริการสำหรับเจ้าหน้าที่จากเว็บเดิม ถ้ามีข้อมูลอยู่แล้วจะไม่เพิ่มซ้ำ ประเภทประกาศ 3 ประเภท (ข่าวประชาสัมพันธ์, จัดซื้อจัดจ้าง/ประกวดราคา, รับสมัครงาน) ถูกสร้างตอน `migrate` อยู่แล้ว

ถ้าต้องการย้ายข้อมูลจากเครื่องที่พัฒนา (หน้าเกี่ยวกับเรา การตั้งค่าเว็บไซต์ ฯลฯ) ให้ส่งออกฐานข้อมูล `bchsp_site` จากเครื่องนั้นมานำเข้าแทนขั้นตอนนี้ และคัดลอกโฟลเดอร์ `storage/app/public` มาด้วย

## 5. สร้างผู้ดูแลระบบคนแรก

เว็บไซต์ไม่มีหน้าสมัครสมาชิก บัญชีแรกต้องสร้างจากเซิร์ฟเวอร์:

```bash
php artisan admin:create
```

จากนั้นเข้าหลังบ้านที่ `/admin` เพิ่มเจ้าหน้าที่คนอื่นได้ที่เมนู ระบบ > เจ้าหน้าที่

บัญชี `admin` รหัสผ่าน `admin` ที่ใช้ระหว่างพัฒนา ห้ามนำขึ้นเซิร์ฟเวอร์จริง ถ้าย้ายฐานข้อมูลจากเครื่องพัฒนามา ให้เปลี่ยนรหัสผ่านหรือลบบัญชีนี้ทันที

## 6. งานตั้งเวลา (ต้องทำ)

การสำรองข้อมูลทุกคืนและการล้างบันทึกเก่าทำงานผ่านงานตั้งเวลา เซิร์ฟเวอร์ต้องเรียกคำสั่งนี้ทุกนาที

**Linux** เพิ่มใน crontab ของผู้ใช้ที่รันเว็บ:

```
* * * * * cd /ที่อยู่/bchsp && php artisan schedule:run >> /dev/null 2>&1
```

**Windows** สร้างงานใน Task Scheduler ให้รันทุก 1 นาที:

```
โปรแกรม:  C:\xampp\php\php.exe
อาร์กิวเมนต์:  artisan schedule:run
เริ่มใน:  C:\ที่อยู่\bchsp
```

ตรวจผลได้ที่หลังบ้าน ระบบ > สถานะระบบ บรรทัด "งานตั้งเวลา" ต้องขึ้นว่าปกติภายใน 3 นาที

## 7. เร่งความเร็ว

รันหลังติดตั้งและทุกครั้งที่อัปเดตโค้ด:

```bash
php artisan optimize
php artisan filament:optimize
```

## 8. การสำรองข้อมูล

- ระบบสำรองฐานข้อมูลและไฟล์ที่อัปโหลดทุกคืนเวลา 03:10 น. เก็บไว้ที่ `storage/app/backups` นาน 14 วัน
- สั่งสำรองทันทีได้ด้วย `php artisan backup:database` หรือปุ่ม "สำรองข้อมูลตอนนี้" ในหน้าสถานะระบบ
- **สำเนาในโฟลเดอร์นี้อยู่บนดิสก์เดียวกับเว็บไซต์** ถ้าดิสก์เสียหรือเครื่องหาย สำเนาจะหายไปด้วย จึงต้องตั้งโฟลเดอร์ที่สองในไฟล์ `.env`:

```ini
BACKUP_COPY_TO=D:/backup/bchsp
```

ระบบจะคัดลอกสำเนาฐานข้อมูลและไฟล์ที่อัปโหลดไปยังโฟลเดอร์นี้ทุกคืนหลังสำรองเสร็จ โฟลเดอร์นี้ควรเป็นอย่างใดอย่างหนึ่ง:

- ดิสก์อีกลูกหรือเครื่องอื่นในเครือข่าย (network share)
- โฟลเดอร์ที่โปรแกรมซิงก์ส่งออกนอกเครื่อง เช่น Google Drive for desktop หรือ OneDrive

ถ้ายังไม่ตั้ง หน้าสถานะระบบจะขึ้นเตือนที่บรรทัด "สำเนาสำรองนอกเครื่อง" และเมื่อมีรายการใดเป็นสีแดง จะมีตัวเลขสีแดงขึ้นที่เมนู "สถานะระบบ" ในหลังบ้าน

กู้คืนฐานข้อมูลจากสำเนา:

```bash
gunzip -c storage/app/backups/db-ปี-เดือน-วัน-เวลา.sql.gz | mysql -u ผู้ใช้ -p ชื่อฐานข้อมูล
```

ไฟล์ที่อัปโหลดอยู่ใน `storage/app/backups/uploads` คัดลอกกลับไปที่ `storage/app/public`

## 9. ตรวจหลังติดตั้ง

1. เปิดหน้าแรกผ่าน HTTPS ได้ และเมนูทุกหมวดเปิดได้
2. เข้า `/admin` ได้ และระบบพาไปตั้งค่ายืนยันตัวตนสองขั้น
3. หลังบ้าน ระบบ > สถานะระบบ ไม่มีบรรทัดสีแดง
4. ลองอัปโหลดประกาศพร้อมไฟล์ PDF แล้วเปิดไฟล์จากหน้าเว็บได้
5. `https://โดเมน/.env` ต้องเปิดไม่ได้ (404 หรือ 403)

## 10. อัปเดตเว็บไซต์ภายหลัง

```bash
php artisan backup:database
git pull
composer install --no-dev --optimize-autoloader
npm ci && npm run build
php artisan migrate --force
php artisan optimize
php artisan filament:optimize
```

## 11. เมื่อมีปัญหา

| อาการ | วิธีแก้ |
|---|---|
| เจ้าหน้าที่ทำมือถือหาย เข้าระบบไม่ได้ | `php artisan two-step:off ชื่อผู้ใช้` (ใช้อีเมลแทนได้) แล้วให้เจ้าของบัญชีตั้งค่าใหม่ |
| รูปและไฟล์ PDF เปิดไม่ได้ | `php artisan storage:link` |
| แก้การตั้งค่าใน `.env` แล้วไม่มีผล | `php artisan optimize:clear` แล้ว `php artisan optimize` |
| หน้าเว็บขึ้นข้อผิดพลาด 500 | ดูไฟล์ `storage/logs/laravel.log` |
| ดิสก์ใกล้เต็ม | ใช้ลิงก์ Google Drive แทนการอัปโหลดไฟล์ใหญ่ในประกาศและ ITA และลบสไลด์เก่าที่ไม่ใช้ |
